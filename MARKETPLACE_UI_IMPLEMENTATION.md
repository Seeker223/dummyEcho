# Emergency Echo Marketplace UI

Added to the System 3 dummy frontend using the supplied Partnership & Marketplace UI spreadsheet as the visual reference.

## Routes

- `/marketplace` — marketplace overview
- `/marketplace/categories` — category directory
- `/marketplace/products` — product listing with search/filter
- `/marketplace/products/aed` — product details
- `/marketplace/vendor` — verified vendor store
- `/marketplace/checkout` — checkout
- `/marketplace/sell` — become-a-vendor

This is UI prototype behavior only. Product inventory, payments, fulfillment, vendor verification, and order persistence are not connected to backend services.
