# Emergency Echo Partnership UI

Implemented against the uploaded `dummyEcho-main (1).zip` using the supplied Partnership & Marketplace UI spreadsheet as the visual source.

## Added routes
- `/partnership` — Partner dashboard overview
- `/partnership/programs` — Partnership programs
- `/partnership/proposal` — New partnership proposal
- `/partnership/directory` — Partner directory
- `/partnership/analytics` — Partnership analytics
- `/partnership/agreement` — Partnership agreement

## Shared UI
`components/PartnershipShell.tsx` provides the dark partner-portal navigation, verified partner state, responsive content shell, and consistent Emergency Echo styling.

## Scope
This is frontend dummy UI. Forms, filters, charts, document actions, and partner actions are visual/local interactions only and are ready for later backend integration.
