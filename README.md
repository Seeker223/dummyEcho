# Emergency Echo — New Frontend UI Dummy Site

A clean, production-oriented frontend prototype derived from the supplied Emergency Echo UI/UX spreadsheets.

## Source direction
- Emergency Echo red/white visual language
- Inter typography
- 8pt spacing system
- Solid surfaces (no glassmorphism)
- Voice-first AI interaction
- LiveKit/WebRTC video-call concepts
- Emergency timeline and AI summary
- Responsive mobile/tablet/desktop layouts

## Routes
- `/dashboard`
- `/ai`
- `/emergency`
- `/doctor`
- `/video-call`
- `/voice-call`
- `/ai-conversation`
- `/timeline`
- `/summary`

## Technology
- Next.js App Router
- React
- TypeScript/TSX
- Tailwind CSS
- Lucide React icons
- LiveKit React/client packages included for the later real-time implementation

This is intentionally a UI dummy site. LiveKit connection/authentication, medical services, notifications, dispatch, and persistence are not implemented here.
